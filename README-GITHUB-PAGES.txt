VORTEXUS 26 — GITHUB PAGES

VERSI INI SUDAH DILENGKAPI CSS + JAVASCRIPT.

CARA UPLOAD KE GITHUB:
1. Buka repository GitHub kamu.
2. Upload SEMUA isi folder VORTEXUS26_LENGKAP, termasuk folder assets.
3. Pastikan file index.html berada di ROOT repository.
4. Pastikan folder assets/css/style.css, assets/js/github-pages.js, dan assets/images/ ikut ter-upload.
5. Masuk Settings > Pages.
6. Source: Deploy from a branch. Branch: main. Folder: / (root). Save.
7. Tunggu beberapa menit lalu buka URL GitHub Pages kamu.

PENTING:
- GitHub Pages hanya menjalankan HTML/CSS/JavaScript. File PHP dan MySQL di paket ini dipertahankan sebagai versi hosting PHP, tetapi TIDAK dijalankan oleh GitHub Pages.
- Versi GitHub Pages memakai IndexedDB + localStorage untuk demo upload/login di browser/perangkat yang sama. Data tidak otomatis tersinkron ke pengunjung lain.
- Jangan upload ZIP sebagai satu file jika ingin GitHub Pages membaca website. Ekstrak ZIP, lalu upload seluruh isi folder repository.
